# Эмулятор оболочки UNIX (Вариант 14)

## Общее описание
Графический эмулятор командной строки UNIX-подобной ОС с виртуальной файловой системой (VFS) в ZIP-архиве.

## Функции и команды
- `ls [путь]` — список файлов и директорий
- `cd <путь>` — смена текущей директории
- `wc <файл>` — подсчёт строк, слов и байт
- `echo <текст>` — вывод текста
- `who` — информация о пользователе
- `mv <откуда> <куда>` — перемещение файлов
- `chown <владелец> <файл>` — смена владельца
- `vfs-init` — сброс VFS к состоянию по умолчанию
- `exit` — выход из эмулятора

## Параметры командной строки
- `--vfs-path` — путь к ZIP-архиву VFS
- `--script` — путь к стартовому скрипту

## Сборка и запуск
```bash
make run      # запуск эмулятора
make test     # запуск тестов
